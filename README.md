# Dra. Grecia Rodríguez

Sitio web para la consulta de **Dra. Grecia Rodríguez** — especialista en rehabilitación oral e implantología en Tegucigalpa, Honduras.

## Configuración

Todo el contenido del sitio se controla desde `js/config.js`. No edites texto directamente en `index.html`.

## Imágenes del cliente

Coloca los archivos de imagen en:

```
assets/images/
  hero.jpg              ← foto principal del hero
  dentist.jpg           ← foto de la doctora (o renombra y actualiza config.js)
  logo.png / logo.svg   ← logo del consultorio (opcional; config.js → branding.logoUrl)
  gallery/
    smile-01.jpg …      ← fotos de galería / antes y después
  financing/
    Bac.png             ← ya incluido
    Ficohsa.png         ← ya incluido
```

## Desarrollo local

```bash
npx serve .
```

Abre `http://localhost:3000` en el navegador.
